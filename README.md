- **Що зрозуміла про тригери, public і private:** Тригер (`Is Trigger`) пропускає об'єкт крізь себе та викликає події дотику замість фізичного блокування; `public` робить змінні доступними в Inspector та для інших скриптів, а `private` захищає дані всередині файлу.
- **Яке значення Time Invincible обрала і для якого гравця:** Обрала **2.0 секунди**, щоб гравець мав достатньо часу вийти із зони шкоди і не втрачав усе здоров'я миттєво.
